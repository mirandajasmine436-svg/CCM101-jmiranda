## ❓ Why Check Disk Space Before a Traffic Surge?
Checking disk space is critical before a massive traffic surge because web servers write data to the disk constantly, including temporary files, caches, and application logs. If the disk fills up to 100%, the server will crash, and the website will go offline. By checking the baseline, we ensure there is enough headroom to handle the flood of incoming data.
