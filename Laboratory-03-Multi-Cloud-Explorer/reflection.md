# Mission Reflection

The cloud platform that impressed me the most was Google Cloud Platform (GCP), especially because of its services for Artificial Intelligence (AI), Machine Learning (ML), data, and Kubernetes. During this mission, I learned that AWS, Microsoft Azure, and GCP have many similarities. All three provide important services such as virtual machines, storage, networking, databases, and identity management. They also allow businesses to use computing resources online and increase or decrease resources depending on their needs. However, each cloud provider has different strengths. AWS has many services and can be useful for startups, large companies, and global applications. Microsoft Azure is a good choice for organizations that already use Microsoft products such as Windows Server, Microsoft 365, and Microsoft Entra ID. GCP is a good option for businesses that focus on AI, Machine Learning, data processing, and Kubernetes. I also learned that business requirements are important when choosing a cloud platform. Companies should consider their budget, existing technology, number of users, type of application, performance, security, and future growth. For example, a university that already uses Microsoft products may choose Azure, while an AI research company may prefer GCP. A startup or global e-commerce company may choose AWS because of its wide range of services and ability to scale. Acting as a Cloud Solutions Consultant taught me that I should understand the client's needs before recommending a platform. I learned that there is no single cloud provider that is best for every company. My GitHub Cloud Computing Portfolio also improved because I added research, comparison tables, recommendations, commands, and screenshots. I became more comfortable using Markdown and organizing my files in GitHub. Overall, this mission helped me understand how cloud platforms are used in real business situations. It improved my skills in comparing services, understanding client requirements, and making cloud recommendations.
