# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It provides extensive cloud services for organizations to build, deploy, store, and manage applications efficiently.


## Global Infrastructure

AWS operates a global cloud infrastructure made up of geographic Regions and Availability Zones. Organizations can deploy applications closer to users, enhancing availability and reliability across 39 Regions and 124 Availability Zones.


## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Centralized AWS console access for managing resources, monitoring usage, and accessing billing information.

## Four Core Services

### 1. Amazon EC2

Amazon Elastic Compute Cloud (EC2) provides virtual servers that organizations can use to run applications and workloads in the cloud.

### 2. Amazon S3

Amazon Simple Storage Service (S3) provides object storage for files, data, backups, and other digital information.

### 3. Amazon VPC

Amazon Virtual Private Cloud (VPC) allows organizations to create isolated virtual networks for their AWS resources.

### 4. AWS IAM

AWS Identity and Access Management (IAM) controls access to AWS resources by allowing administrators to manage users, roles, and permissions.

## Three Advantages

1. **Wide range of services** – AWS provides many services for computing, storage, networking, databases, security, and other cloud requirements.
2. **Global infrastructure** – AWS has regions and availability zones around the world, allowing organizations to deploy applications globally.
3. **Scalability** – AWS allows organizations to increase or decrease resources based on their workload requirements.

## Typical Enterprise Use Cases

AWS is commonly used by enterprises for web application hosting, data storage and backup, database systems, business applications, analytics, and large-scale digital services. Organizations can combine different AWS services to create scalable and highly available cloud infrastructures.
