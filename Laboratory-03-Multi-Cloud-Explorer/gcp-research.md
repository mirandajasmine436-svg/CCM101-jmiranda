# Google Cloud Platform (GCP) Research

## Brief Overview

Google Cloud Platform (GCP), commonly called Google Cloud, is a cloud computing platform provided by Google. It provides infrastructure, computing, storage, database, networking, artificial intelligence, and data analytics services.

## Global Infrastructure

Google Cloud operates a global infrastructure with regions and zones distributed around the world. Google Cloud's infrastructure supports deployments across more than 200 countries and territories and provides regional and multi-region options for cloud workloads.

## Cloud Management Console

The Google Cloud Console is a web-based interface used to manage and monitor Google Cloud resources and applications. Users can manage services, projects, resources, security, monitoring, and other cloud operations through the console.

## Four Core Services

### 1. Compute Engine

Compute Engine provides virtual machines that organizations can use to run applications and workloads in Google Cloud.

### 2. Cloud Storage

Cloud Storage provides object storage for files, backups, application data, and other digital information.

### 3. Virtual Private Cloud (VPC)

Google Cloud VPC provides networking capabilities that allow organizations to connect and manage cloud resources securely.

### 4. Cloud IAM

Cloud Identity and Access Management (IAM) allows organizations to control who can access Google Cloud resources and what actions they are allowed to perform.

## Three Advantages

1. **Strong AI and data capabilities** – Google Cloud provides services designed for artificial intelligence, machine learning, analytics, and large-scale data processing.
2. **Global infrastructure** – Google Cloud provides infrastructure distributed across regions and locations around the world.
3. **Kubernetes support** – Google Cloud provides Google Kubernetes Engine (GKE), a managed Kubernetes service for deploying and managing containerized applications.

## Typical Enterprise Use Cases

Google Cloud is commonly used for artificial intelligence and machine learning, big data analytics, application hosting, containerized applications, databases, and global web services.
