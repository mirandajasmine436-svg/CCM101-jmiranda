# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think the **compute component** is one of the most important parts of cloud infrastructure because it provides the processing power needed to run applications, services, and workloads. Without compute resources such as CPUs and memory, cloud applications would not be able to operate. Choosing the appropriate compute resources is also important because it affects the performance, reliability, and cost of a cloud environment.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a stable, secure, flexible, and efficient operating system for cloud servers. It can run on different types of hardware and can be managed using command-line tools. During this laboratory activity, I used Linux commands to inspect information about the CPU, memory, storage, disk usage, and network configuration of the cloud server. Linux is also widely used for servers because it can be customized and efficiently managed.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of the infrastructure, configurations, requirements, and procedures. It helps prevent mistakes before deployment and makes it easier to troubleshoot problems. Good documentation also allows other team members to understand the system and reproduce the configuration when needed.

## 4. What new skills did you learn during this laboratory activity?

I learned how to use Linux terminal commands to inspect cloud server resources. I also learned how to organize information using Markdown files, create and manage files in Ubuntu, and use Git commands to track changes. These activities improved my understanding of cloud infrastructure and Linux administration.

## 5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio improved because I added a documented cloud infrastructure project that demonstrates my practical skills. The project contains information about the cloud environment, system resources, and my reflections about the activity. It shows that I can use Linux, Git, GitHub, and Markdown to document and manage a technical project.
